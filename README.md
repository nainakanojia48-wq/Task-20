### Laundry Service Website

I created a responsive laundry service website using **HTML, CSS, and JavaScript**. Users can view available laundry services, add or remove services from the cart, and see the total price automatically. The website also includes a booking form, newsletter subscription, service details, and a responsive design for mobile and desktop. **EmailJS** is used to send booking and newsletter emails.


## Features

* Responsive navigation bar with Home, Services, About Us, and Contact Us.
* Hero section with a "Book a Service Today" button.
* Displays laundry service achievements and experience.
* Shows different laundry services with their prices.
* Users can add services to the cart.
* Users can remove services from the cart.
* Total price is calculated automatically.
* Booking form with name, email, and phone number.
* Booking confirmation message after submitting the form.
* EmailJS integration for sending booking emails.
* Newsletter subscription form.
* EmailJS can also be used to receive newsletter subscription details.
* Quality section showing premium service, quick support, timely delivery, and affordable prices.
* Footer with useful links and social media icons.
* Mobile-friendly and responsive design.

## How to Run

1. Download or clone the project.
2. Open the project folder in **VS Code**.
3. Make sure these files are in the same folder:

   * `index.html`
   * `style.css`
   * `script.js`
4. Open `index.html` in your browser.

### For EmailJS

1. Create an account on EmailJS.
2. Connect your Gmail account.
3. Create an email service and templates.
4. Add your **Public Key, Service ID, and Template ID** to the project.
5. Open the website and test the booking and newsletter forms.

That's it! The laundry service website is ready to use.
