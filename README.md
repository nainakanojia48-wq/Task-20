# Fresh Laundry

Fresh Laundry is a simple laundry service website made using HTML, CSS and JavaScript.

The website allows users to view laundry services, add services to a cart, check the total amount and book a laundry service.

## Features

- Responsive navigation bar
- Home section
- Services section
- About us section
- Contact us section
- User name and logo in navbar
- Hero section with laundry image
- Book a service button
- Service achievements section
- Laundry service list
- Add items to cart
- Remove items from cart
- Total amount calculation
- Cart data stored using localStorage
- Booking form
- Full name validation
- Email validation
- Phone number validation
- Booking confirmation using EmailJS
- Booking success message
- Newsletter subscription form
- Newsletter email using EmailJS
- Quality description section
- Responsive design
- Footer with useful links and social media links

## Technologies Used

- HTML
- CSS
- JavaScript
- EmailJS
- localStorage

## Project Files

The project contains three main files:

### index.html

This file contains the structure of the website such as:

- Navbar
- Hero section
- Services
- Booking form
- Quality section
- Newsletter
- Footer

### style.css

This file is used for:

- Website design
- Layout
- Colors
- Buttons
- Animations
- Transitions
- Responsive design

### script.js

This file is used for:

- Displaying services
- Adding services to cart
- Removing services from cart
- Calculating total amount
- localStorage
- Form validation
- Booking functionality
- EmailJS
- Newsletter functionality

## EmailJS

EmailJS is used to send emails when:

1. A user books a laundry service.
2. A user subscribes to the newsletter.
